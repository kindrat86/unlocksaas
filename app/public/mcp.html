MCP Server · Free · No auth

UnlockSaaS MCP Server

Call UnlockSaaS SaaS unit-economics calculators from Claude Desktop, Cursor, or Windsurf. One endpoint. Stateless Streamable HTTP. No API key.

https://unlocksaas.com/api/mcp

All three tools are pure functions of public SaaS-finance formulas (David Skok / Bessemer / Tunguz). No sign-up, no email gate — the same math the $49 Playbook walks through.

Install in Claude Desktop

Add to ~/Library/Application Support/Claude/claude_desktop_config.json (macOS):

{
  "mcpServers": {
    "unlocksaas": {
      "command": "npx",
      "args": ["mcp-remote", "https://unlocksaas.com/api/mcp"]
    }
  }
}

Install in Cursor

Add to .cursor/mcp.json in your project root:

{
  "mcpServers": {
    "unlocksaas": {
      "url": "https://unlocksaas.com/api/mcp"
    }
  }
}

Install in Windsurf

Settings → MCP Servers → Add new MCP server → Type: url:

{
  "mcpServers": {
    "unlocksaas": {
      "serverUrl": "https://unlocksaas.com/api/mcp"
    }
  }
}

Inspect / debug

npx @modelcontextprotocol/inspector https://unlocksaas.com/api/mcp

Available tools (3)

get_ltv

Customer lifetime value from ARPU, gross margin, and monthly churn. LTV = (ARPU × Gross Margin) / Monthly Churn.

get_churn_cost

Monthly revenue lost to churn from MRR, churn rate, and optional customer count. Returns lost MRR, annualized loss, and per-customer cost.

project_revenue

Project SaaS revenue forward from current MRR and a monthly growth rate. Returns a month-by-month series.

Try it

curl -X POST https://unlocksaas.com/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_ltv","arguments":{"arpu":49,"gross_margin":0.85,"monthly_churn":0.05}}}'}
