Frequently asked questions

Is GitHub free for indie founders?

Yes. GitHub Free includes unlimited public and private repositories, Actions minutes (2,000/month), and project management features — more than enough for indie SaaS.

Should I open-source my SaaS?

Not necessarily the full product, but open-sourcing components (SDKs, libraries, themes) can drive traffic and credibility. The UnlockSaaS curriculum covers building-in-public strategies that work for indie founders.

GitHub vs GitLab?

Either works. The curriculum uses GitHub as the reference because of its larger community and Actions ecosystem, but the principles apply to any Git platform.
