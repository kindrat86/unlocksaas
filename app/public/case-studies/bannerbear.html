How Bannerbear Hit $500K+ ARR — Solo

Case Study

Bannerbear is an API for generating images and videos — og:images, social media graphics, video thumbnails. Built and run by one person, Jon Yongfook. Over $500K annual recurring revenue. Zero employees.

The Story

Jon had built multiple SaaS products before Bannerbear. He noticed a pattern: every SaaS he built needed to generate images programmatically — og:images, email headers, social share cards. The tools that existed were either too expensive (Cloudinary) or too limited (HTML-to-image converters). He built an API that did exactly one thing well: take a template + data, return an image.

What Worked

  1. API-first positioning: Bannerbear's landing page is an API reference. The docs are the marketing. Developers who `curl` the API convert at 3-5x the rate of homepage visitors. Jon invested in documentation quality the way other founders invest in ad spend.
  2. Pricing that scales with usage: Bannerbear's free tier includes 100 API calls/month. The Pro tier ($49/mo) includes 1,000. The customer who sends 10,000 calls/month naturally upgrades — no sales call, no "talk to sales," no friction.
  3. Use-case pages as SEO: Jon built pages for every use case: "og:image generator," "Twitter card generator," "email header generator." Each page ranks for its exact use case. Combined, these pages drive 60% of new signups.

Key Numbers

  • Revenue: $500K+ ARR
  • Team: 1 (solo founder)
  • Launched: 2019
  • API calls processed: millions/month
  • Customer acquisition channel: 60% organic SEO via use-case pages, 20% word-of-mouth, 20% affiliate/referral

What Indie Founders Should Steal

Docs are your landing page. If you build an API product, invest 3x more time in documentation than in your marketing site. Developers convert when they can `curl` and get a result in under 30 seconds.

Pricing that upgrades itself. Don't build a "talk to sales" enterprise tier until you have at least 10 customers asking for it. Usage-based pricing upgrades customers automatically — no human required.
