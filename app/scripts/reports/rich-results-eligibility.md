## Method

- One representative URL per canonical hub template (real, sitemap-verified slug).
- For each URL: GET HTML, extract every `<script type="application/ld+json">`,
  recurse into `@graph` arrays, grade each node carrying a known `@type`.
- Rules sourced from Google's structured-data eligibility docs
  (linked at the top of the script).
- Severity:
  - 🔴 **required** — Google will not render the rich result without it.
  - 🟡 **recommended** — Google may render a degraded rich result; full eligibility wants it.
  - 🟠 **eligibility check** — type-specific deeper rule (e.g. FAQ ≥2 Q, Article author = Person not string).

Re-run: `node scripts/rich-results-eligibility.mjs` (or via `npm run validate:richresults`).
